Screens & Broadcasting

Display URLs

Open any URL below in a browser or add it as an OBS browser source (1080 × 1920 for portrait).

    OBS Setup

    1. Add a Browser Source with one of the URLs above.

    2. Set resolution to 1080 × 1920.

    3. Enable hardware acceleration (Settings → Advanced).

    4. Set canvas to 1080 × 1920.

    Phone Kiosk Mode

    Open a display URL with ?kiosk=1 on your phone.

    Tap once to enter full screen, then start a LIVE with screen sharing — no PC needed.

    Multi-Platform Streaming

    Use scripts/pi-stream.sh on a GPU machine (Pi 5, PC, VPS) to stream to multiple platforms.

    Set DESTS="rtmp://… rtmps://…" for YouTube + Facebook + TikTok.

    External Bridge

    POST events to /api/events with the admin password as secret to bridge YouTube or Twitch chat.

    Contract: {secret, events: [{type, username, text, …}]}
